# IMG→A4·PDF

批量上传图片，拉伸到 A4 纸张大小，并生成可打印 PDF 的工具。界面采用国际主义风格（Swiss Style），纯本地处理，图片不上传服务器。

## 功能

- 批量上传 / 拖拽上传图片（JPG / PNG / BMP / WebP）
- 预览网格：排序、旋转 90°、删除
- 两种填充模式：拉伸铺满（默认）/ 等比留白
- 一键生成 A4 PDF（210 × 297 mm，每图一页）
- 超大图片自动压缩，控制文件体积
- 本地处理，保护隐私

## 使用

- 在线使用：<https://iiistudio.github.io/IMG-A4-PDF>
- 本地使用：直接用浏览器打开 `index.html` 即可（jsPDF 通过 CDN 加载，首次需联网）。
